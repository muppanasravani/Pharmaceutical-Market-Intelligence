# Pharmaceutical Market Intelligence & Brand Performance Analytics

## Project Overview
This project analyzes pharmaceutical market performance using SQL and Power BI. It focuses on competitor performance, product segments, therapeutic areas, regional sales, and revenue trends.

The project demonstrates data management, SQL querying, and business intelligence dashboard development.

## Tools & Technologies
- MySQL Workbench
- Microsoft Power BI Desktop
- SQL
- DAX
- CSV datasets

## Dataset
The project uses simulated pharmaceutical market data covering 2023–2025.

The database contains five tables:
- dim_competitor
- dim_product
- dim_region
- dim_date
- fact_sales

**Disclaimer:** The dataset is synthetic and created for educational and portfolio purposes. It does not represent actual IQVIA or commercial pharmaceutical sales.

## Key Performance Indicators
- Total Revenue
- Average Revenue
- Total Transactions
- Total Units Sold

## Dashboard Analysis
- Revenue by Pharmaceutical Competitor
- Revenue by Therapeutic Area
- Yearly Revenue Trend
- Year and Region filtering

## Project Workflow
1. Created a relational database using MySQL Workbench.
2. Organized pharmaceutical market data into dimension and fact tables.
3. Exported database tables as CSV files.
4. Imported the datasets into Power BI.
5. Created data model relationships.
6. Developed DAX measures and interactive dashboard visualizations.

## Business Applications
- Competitor performance monitoring
- Therapeutic area revenue comparison
- Regional market analysis
- Revenue trend monitoring
- Pharmaceutical market intelligence
